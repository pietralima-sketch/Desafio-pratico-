# Desafio-pratico-
fazer html, css e javascript


Integrante- Pietra , toda vida. 


Descricoes-

• Player de Música Interativo (Clone do Spotify)

	• O que faz: Um reprodutor de áudio completo com capa do álbum, nome da música, botões de play, pause, avançar, voltar e uma barra de progresso dinâmica.

	• Tecnologias envolvidas: Uso da tag nativa <audio> do HTML5, estilização moderna e responsiva com CSS (Flexbox/Grid), e controle de eventos e manipulação do DOM em JavaScript (play(), pause(), alteração de faixas).

instrucoes- 

1-Criar um repositório no GitHub para o projeto e adicionar o outro integrante da dupla como colaborador.= feito

2-Cada integrante deverá criar sua própria branch, preferencialmente identificada pelo nome, por exemplo branch-joao e branch-maria.- feito

3-A dupla escolherá livremente o projeto que deseja desenvolver, desde que utilize obrigatoriamente HTML, CSS e JavaScript.= Escolha feita

4-O projeto deverá possuir, no mínimo, cabeçalho, área principal, rodapé, imagens, pelo menos um vídeo e funcionalidades desenvolvidas com JavaScript.= ainda nao feito


5-Cada integrante deverá desenvolver uma parte do projeto em sua própria branch e realizar commits identificáveis e organizados. Não será suficiente um único integrante fazer todo o projeto.= em andamento

6-Após concluir as partes individuais, a dupla deverá realizar o merge das duas branches para a main, resolvendo eventuais conflitos.= ainda nao feito

7-O projeto final deverá funcionar corretamente após o merge, sem perder funcionalidades desenvolvidas por nenhum dos integrantes.= ainda em andamento

8-O repositório deverá possuir um arquivo README.md com nome dos integrantes, descrição do projeto, funcionalidades implementadas, tecnologias utilizadas e divisão das responsabilidades.= feito

9-A dupla deverá publicar o projeto pelo GitHub Pages e entregar um único link do repositório e um único link do site publicado. nao feito ainda
